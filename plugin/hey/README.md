# Hey by Ars

Connect the private Hey gateway with OAuth. Use hey_status to inspect real device state and hey_pair for the one-time Android pairing link. Browser tools return durable task handles. Read hey_task until terminal status and page through its original image/audio evidence. A queued command, a click or a playback-end flag does not prove that the requested outcome or audiovisual understanding was achieved.

Private package 0.1.0. Android, audio, dormant wake, browser compatibility and target-host media handling have separate verification gates. Source: arsafiqri-aybi/hey-mcp and arsafiqri-aybi/hey-android.
